# Product Requirements Document: Monitor App MVP

## 1. Global System Rules
- CRITICAL RULE: Never add comments inside code for any language, type, snippet, or file.
- The project is a monorepo containing: apps/mobile-app (Ionic/Angular), apps/backend (NestJS), and infrastructure/ (Docker).

## 2. Product Overview
A secure, monitored video communication platform using self-hosted Jitsi.
- Target Users: Inmates, Families, and Admin Monitors.
- MVP Auth Strategy: No authentication (`ENABLE_AUTH=0`). Security is handled via unguessable room UUIDs generated by the backend.

## 3. Backend Requirements (NestJS + PostgreSQL)
- Tech: NestJS, TypeORM, PostgreSQL.
- Database Entity `CallSession`:
  - id (UUID, primary key)
  - roomUuid (String, unique, format: `call-<uuid>`)
  - status (String, default: 'active', can be 'ended')
  - masterFilePath (String, nullable, stores the path to the Jibri mp4 recording)
- Endpoints:
  - `POST /calls/create`: Generates a new roomUuid, saves to DB, returns the UUID.
  - `GET /calls/active`: Returns all calls where status is 'active'.
  - `PATCH /calls/:id/end`: Updates status to 'ended'.
- Background Task:
  - Implement a simple file-watcher or cron job using Node's `fs` or `chokidar`. It must watch the local directory where Jibri saves `.mp4` recordings. When a recording finishes, update the corresponding `CallSession.masterFilePath` in the database.

## 4. Frontend Requirements (Ionic Angular + Capacitor)
- Tech: Angular 17+, Ionic Framework.
- Integration: Use JitsiMeetExternalAPI via iframes for all video calls.
- View 1: Participant View (Inmate/Family)
  - Loads the Jitsi iframe using the room UUID.
  - Bandwidth constraint: Pass `resolution: 360` in `configOverwrite`.
  - UI restriction: Hide all Jitsi UI elements except the hangup button. `prejoinPageEnabled: false`.
- View 2: Admin Monitoring Dashboard
  - Fetches and displays a list of active calls from `GET /calls/active`.
  - Clicking a call loads the Jitsi iframe to join that specific room.
  - Silent Entry: Monitor must join completely hidden (`startWithAudioMuted: true`, `startWithVideoMuted: true`, `prejoinPageEnabled: false`).
  - Monitor Controls:
    - "Intervene" button: Executes `api.executeCommand('toggleAudio')` to unmute the admin.
    - "Terminate Call" button: Executes `api.executeCommand('endConference')` to kick everyone out, then calls `PATCH /calls/:id/end` on the backend.

## 5. Infrastructure Requirements (DevOps)
- Tech: Docker Compose.
- Stack: Official `jitsi/web`, `jitsi/prosody`, `jitsi/jicofo`, `jitsi/jvb`, and `jitsi/jibri`.
- Configurations:
  - `ENABLE_AUTH=0` and `ENABLE_GUEST_MODE=1` to allow instant access via UUID.
  - Configure Jibri to record locally to a mapped volume (`/recordings`). This mapped volume must be shared with the NestJS backend container so the backend can detect and log the finished `.mp4` files.
